CakeShop — интернет-магазин тортов

Учебный проект: интернет-магазин тортов с оплатой при получении (COD).
Написан на чистом PHP, MySQL, HTML, CSS и JavaScript — без фреймворков и CMS.

Возможности

Для покупателей:
— Каталог тортов с фильтрами (категория, цена, поиск)
— Карточка товара с описанием и фото
— Корзина (хранится в сессии)
— Оформление заказа с оплатой при получении
— Регистрация и вход
— Личный кабинет с историей заказов и статусами

Для администратора:
— Управление тортами: добавление, редактирование, удаление
— Загрузка фотографий
— Просмотр заказов с фильтром по статусу
— Смена статуса заказа (новый → подтверждён → готовится → в доставке → получен)

Стек

— PHP 8 — серверная логика
— MySQL / MariaDB — база данных
— PDO — работа с БД через prepared statements
— HTML5 / CSS3 — вёрстка
— JavaScript — интерактив на клиенте

Установка

1. Требования

— PHP 8.0+
— MySQL 5.7+ или MariaDB 10.4+
— Apache или встроенный PHP-сервер

2. Клонирование

git clone https://github.com/ВАШ_ЛОГИН/cakeshop.git
cd cakeshop

3. Настройка базы данных

Импортируйте database/schema.sql через phpMyAdmin или командой:

mysql -u root -p < database/schema.sql

Будет создана база cakeshop с таблицами и тестовыми данными (50 тортов).

4. Настройка подключения

Откройте includes/db.php и укажите свои данные:

$DB_HOST = 'localhost';
$DB_NAME = 'cakeshop';
$DB_USER = 'root';
$DB_PASS = '';

5. Запуск

Через XAMPP: положите папку в htdocs/ и откройте http://localhost/SHOP/

Через встроенный сервер PHP:

php -S localhost:8000

Откройте http://localhost:8000

6. Создание администратора

— Зарегистрируйтесь на сайте
— Откройте phpMyAdmin → база cakeshop → таблица users
— У своей записи поменяйте role на admin
— Обновите страницу — в шапке появится ссылка «Админка»

Безопасность

— Пароли хранятся через password_hash() (bcrypt)
— Все SQL-запросы через PDO prepared statements — защита от инъекций
— Вывод данных экранируется через htmlspecialchars() — защита от XSS
— CSRF-токены на формах
— Цены при оформлении заказа берутся из БД, а не из формы
— Оформление заказа обёрнуто в SQL-транзакцию
