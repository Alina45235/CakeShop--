CakeShop — интернет-магазин тортов

Учебный проект: интернет-магазин тортов с оплатой при получении (COD).
Написан на чистом PHP, MySQL, HTML, CSS и JavaScript — без фреймворков и CMS.

Возможности

Для покупателей:
— Каталог тортов с фильтрами (категория, цена, поиск)
— Карточка товара с описанием и фото
— Корзина (хранится в сессии)
— Оформление заказа с оплатой при получении
— Регистрация и вход
— Личный кабинет с историей заказов и статусами

Для администратора:
— Управление тортами: добавление, редактирование, удаление
— Загрузка фотографий
— Просмотр заказов с фильтром по статусу
— Смена статуса заказа (новый → подтверждён → готовится → в доставке → получен)

Стек

— PHP 8 — серверная логика
— MySQL / MariaDB — база данных
— PDO — работа с БД через prepared statements
— HTML5 / CSS3 — вёрстка
— JavaScript — интерактив на клиенте
